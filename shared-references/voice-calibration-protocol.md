# SuperC 真人语气校准协议

## 硬门槛

任何写稿、改稿、选题成稿或商单文案任务，必须先读取 `knowledge_base/数据复盘/` 中已经真实发布的最终文案，再开始写正文。草稿、预测稿、对标账号文案和 AI 生成初稿不能作为真人语气的主要依据。

默认读取最近 3 条同类型已发布文案；如果同类型不足 3 条，读取最近可用样本，并明确标注样本不足。

## 校准顺序

1. 先读账号策略，确定这条内容的任务和边界；
2. 再读数据复盘中的真实发布文案，提取真实句长、口头连接词、停顿、态度和结尾方式；
3. 再读文案口语和 `script_patterns.md`，只用于补充已经在真人文案中出现过的结构；
4. 写稿时优先复现用户真实使用过的表达，不得为了“更像短视频”自行添加营销号词；
5. 输出前标注参考了哪些真实发布样本，并检查成稿是否出现用户从未使用的腔调。

## 真实性边界

- “符合真人语气”不等于机械复制固定句式；
- 对标账号的表达只能作为拆解对象，不能直接混入 SuperC 语气；
- 口语知识库与真实发布文案冲突时，以较新的真实发布文案为准；
- 新出现的表达先标记为“待验证语气”，至少经过一次真实发布和复盘后，才可沉淀为正式风格规则；
- 如果没有可用的真实文案，先说明缺口，不得声称已经完成真人语气校准。
