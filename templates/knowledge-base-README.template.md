# 账号知识库

> 本目录由「SuperC的AI运营助手」初始化时自动创建。
> 所有账号相关资料统一存放于此，写文案、做分析、找选题前先来查这里。

---

## 目录结构

```
knowledge_base/
├── README.md        # 本文件（索引）
├── 对标账号/         # 对标博主分析、最新动态
├── 文案口语/         # 口语风格、写作模板、script patterns
├── 爆款规律/         # 爆款拆解、评分规则、真实数据规律
├── 选题池/           # 候选选题
├── 数据复盘/         # 历史数据、复盘记录
└── 账号策略/         # 账号定位、转型、变现规划
```

## 使用规则

### 写文案前必查
1. 先读 `文案口语/` — 确认语气符合你的风格
2. 再读 `爆款规律/` — 套用已验证的写作模式
3. 最后读 `对标账号/` — 看对标博主最近在做什么

### 找选题前必查
1. 先读 `选题池/` — 看已有候选
2. 再读 `对标账号/` — 看对标博主最近发了什么
3. 最后读 `爆款规律/` — 验证选题方向

### 复盘时必查
1. 先读 `数据复盘/` — 看历史数据
2. 再读 `爆款规律/` — 更新评分规则
3. 最后更新 `文案口语/` — 沉淀新发现的写作模式
