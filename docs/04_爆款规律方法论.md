# 04 · 爆款规律方法论：怎么从自己的数据里挖规律

> 本文件教你**方法**，不给你结论。别人的爆款规律对你可能无效——平台算法在变、赛道在变、你的观众在变。
> 你要做的：用这套方法，从**你自己的真实数据**里挖出只属于你的规律。

---

## 一、先统一指标口径（每次复盘都记同一套）

| 指标 | 怎么记 |
|---|---|
| 播放 | 发布后 1h / 3h / 24h / T+3d 各记一次 |
| 点赞 | 同上时间窗 |
| 收藏 | 同上（**收藏比赞更值钱**——代表"想留着以后用"） |
| 评论 | 总数 + top 评论原文（评论才是真信号） |
| 转发 / 分享 | 同上 |
| 完播率 | 平台后台有就看（不是所有平台都开放） |

**派生指标**（用工具算，不要心算）：
- **藏赞比** = 收藏 ÷ 点赞。>1 说明"实用型"内容；远小于 1 说明"情绪型"
- **互动率** =（赞+藏+评+转）÷ 播放。平台推流考核的核心
- **1h 播放占比** = 1h 播放 ÷ 24h 播放。判断初始池质量

---

## 二、怎么分析（三步）

### 第 1 步：分桶对比（找差异）

把你的内容按表现分成高 / 中 / 低三桶，然后逐项对比：

- **高表现**内容：标题句式？开头钩子类型？主题？时长？封面？
- **低表现**内容：同上，逐项找差异
- 找"高表现共同有、低表现共同无"的特征 → 这就是候选规律

### 第 2 步：看时间窗（找推流节奏）

- 1h 赞 × 9~11 ≈ 最终赞（只是一个经验量级，**用你自己的数据回归**）
- 收藏 > 赞 且互动率高的内容，平台会二次推流
- 阶梯式慢推 ≠ 限流，先观察 24-48h 再判断

### 第 3 步：挖评论模因（找内容资产）

- 评论区有没有观众在**玩你的梗** / 复述你的句式？
- top 评论点赞最高的那条，说明观众被什么击中
- 把"被引用的句式"收进你的 script_patterns.md → 这是你最值钱的内容资产

---

## 三、验证流程（规律入库门槛）

| 规则 | 说明 |
|---|---|
| 至少 2 次验证 | 新规律必须 ≥2 次实际跑出（发布后数据支撑），才写进知识库 |
| 标注证据 | 每条规律写清楚"来自哪几条样本" |
| 允许推翻 | 被新数据推翻的规律**删掉**，不留"考古层"（git 历史才是档案） |
| 不抄别人的 | 别人的规律只能当假设，验证权在你自己的数据 |

---

## 四、常见误区

1. **用 1 条爆款下结论** → 样本不足。最少 5 条分桶才有信号
2. **只记播放不记评论** → 播放告诉不了你观众被什么击中
3. **规律永不再看** → 平台算法改版后旧规律会失效，建议每月重验一次
4. **把平台机制当自己规律** → 藏赞比、互动率这些是平台规则，规律是你的**内容特征**（钩子类型、主题、句式）
