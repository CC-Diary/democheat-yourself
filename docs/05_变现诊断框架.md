# 05 · 变现诊断框架（通用版）

> 变现不是"粉丝多了自然来钱"，是**设计**出来的。
> 本框架帮你按顺序回答 4 个问题，AI 会基于你的账号数据逐项给建议。

---

## 第 1 步：你的粉丝画像（谁在看）

| 问题 | 为什么重要 |
|---|---|
| 粉丝为什么关注你？（干货 / 情绪 / 人设 / 娱乐） | 决定他们愿不愿意花钱 |
| 他们的身份？（学生 / 上班族 / 创业者 / 宝妈） | 决定消费能力和决策速度 |
| 他们现在为你做了什么？（点赞 / 收藏 / 评论 / 私信） | 收藏 > 赞 说明"实用粉"，付费意愿更高 |

**判断信号**：纯娱乐粉（看完就走）付费意愿低；干货粉（收藏存着用）付费意愿高。

## 第 2 步：你的信任资产（粉丝信你什么）

- **干货能力**：你教的东西真的有用 → 适合知识付费
- **真实人设**：粉丝信你这个"人" → 适合社群 / 陪跑
- **情绪共鸣**：粉丝喜欢你的态度 → 适合内容广告 / 周边

**铁律**：变现方式必须匹配信任资产。干货号硬卖人设 = 掉粉；人设号硬卖课程 = 翻车。

## 第 3 步：变现渠道（在哪收钱）

**平台内（推荐起步，零门槛）**：
- 广告商单（粉丝量 + 内容质量达标后平台会开放）
- 笔记付费 / 知识专栏（小红书）
- 薯店 / 小店卖货（虚拟资料、课程、实物）
- 私信通（把高意向粉丝接住）

**平台外（有基础后）**：
- 私域（微信 / 社群）
- 独立课程平台

> ⚠️ 注意平台规则：广告要标注、导流要合规（各平台对站外导流有严格限制），违规会被限流甚至封号。

## 第 4 步：定价阶梯（怎么设计）

通用结构（具体价格结合你的粉丝量和信任度）：

| 层级 | 产品 | 作用 |
|---|---|---|
| 低价引流品 | 9.9-99 元：工具包 / 资料包 / 模板 | 测试付费意愿，筛出真粉 |
| 中价产品 | 199-999 元：社群 / 课程 / 训练营 | 主要利润来源 |
| 高价产品 | 1000+ 元：陪跑 / 定制 / 1v1 | 服务深度用户，高客单 |

**设计原则**：
1. 引流品必须**超值**（让人觉得"9.9 捡到了"）
2. 每一级都是下一级的入口（用过引流品的用户，买课程的转化率高得多）
3. 先测试再上量：挂 2 周引流品看付费数据，再决定课程定价

---

## AI 会怎么帮你

在账号诊断报告的「变现建议」章节，AI 会基于你的**真实样本数据**（粉丝互动模式、内容类型、评论反馈）逐项回答上面 4 个问题，并给出本周可执行的变现动作。结论都是假设，最终以你的测试数据为准。

---

> 本框架为通用商业逻辑，不构成任何投资/商业承诺。平台规则以各平台最新官方说明为准。
