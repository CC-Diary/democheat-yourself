# 01 · 5 分钟上手：从安装到账号诊断报告

> **SuperC的AI运营助手** — 把"感觉"变成可校准预测的内容创作系统。
> 装好后：**初始化 → 给主页链接 → 出诊断报告 → 每天按系统运营**。

---

## 第 1 步：安装（2 分钟）

### 如果你用豆包（推荐，零门槛）

1. 解压工具包，找到 `cheat-yourself` 文件夹
2. 把 `cheat-yourself` 整个文件夹，复制到豆包能读取技能的位置（你的 AI 助手技能目录）
3. 重开一个豆包会话，就装好了

### 如果你用 Claude Code 或 Codex

```bash
# 在 cheat-yourself 目录下
bash install.sh            # Claude Code
bash install.sh --codex    # Codex
```

---

## 第 2 步：初始化（2 分钟）

在你的内容项目文件夹（新建一个空文件夹当项目）里，对你的 AI 助手说：

```
初始化
```

AI 会问你 6 个问题（内容形态、时长、发布频率、有没有发过历史、怎么收数据、有没有候选选题），**一个个回答就行**。

完成后 AI 会自动帮你创建整套工作台：

```
你的项目/
├── .cheat-state.json      # 系统状态
├── rubric_notes.md        # 你的评分规则
├── script_patterns.md     # 你的写作模式库
├── benchmark.md           # 对标账号档案
├── audience.md            # 受众画像
├── WORKFLOW.md / STATUS.md
├── knowledge_base/        # ⭐ 你的知识库（自动建好 6 个分类）
│   ├── 对标账号/           # 对标博主分析
│   ├── 文案口语/           # 口语风格、写作模板
│   ├── 爆款规律/           # 爆款拆解、评分规则
│   ├── 选题池/             # 候选选题
│   ├── 数据复盘/           # 历史数据、复盘记录
│   └── 账号策略/           # 账号定位、变现规划
├── scripts/  predictions/  videos/  samples/
```

---

## 第 3 步：给主页链接，让 AI 分析你的账号（5 分钟）

对你的 AI 助手说：

```
导入对标账号
```

AI 会引导你提供素材，你只需要准备两样东西（详见《02_客户数据提供清单》）：

1. **你想对标/分析的账号主页链接**
2. **这个账号的 5-10 条内容数据**（标题 + 播放 + 点赞 + 评论 + 转发，一条一条告诉 AI 就行）

AI 会自动：
- 拆解每条内容的脚本结构 → 提炼**写作模式**（写进 script_patterns.md）
- 打 7 维分 → 找出"高表现内容共有的维度" → 派生你的**初始评分信号**
- 总结**选题方向感** → 知道该往哪使劲

> 💡 第一次分析建议 10-15 分钟，之后每次追加新内容只要 2 分钟。

---

## 第 4 步：看你的账号诊断报告

分析完成后，对你的 AI 说：

```
帮我的账号出一份诊断报告
```

AI 按《账号诊断报告》模板输出：账号概览 → 7 维打分 → 爆款规律 → 对标差距 → 选题推荐 → 变现建议 → 下一步行动。

---

## 第 5 步：进入日常运营循环

| 你说 | 系统做什么 |
|---|---|
| `推荐选题` | 从候选池按你的公式排序推荐 |
| `打分这篇 scripts/xxx.md` | 7 维打分（不写文件） |
| `启动预测 scripts/xxx.md` | 盲预测 + 预测日志落盘（写后不可改） |
| `拍了 scripts/xxx.md` | 建视频目录，库存 +1 |
| `已发布 https://...` | 登记发布，库存 -1 |
| `复盘 videos/xxx/` | T+3 天收真实数据，对账，学 pattern |
| `状态` | 完整看板：库存颜色 / 待复盘 / 候选池 |
| `升级公式` | 校准池全量重打 + 跨模型审核后进化评分规则 |

**每发一条，你的判断公式就进化一次。** 一个月后你有一套只属于你的爆款公式。

---

## 三条铁律（为什么这套系统有用）

1. **盲预测**：预测必须在看到数据前写完，写完不可改——这是整个系统的唯一信号源
2. **升级 = 全量重考**：改公式时所有历史样本用新公式重打，新排序与真实表现排序对比达标才放行
3. **工作台不留废料**：被数据推翻的观察删掉，文件只留当下最 sharp 的判断依据
