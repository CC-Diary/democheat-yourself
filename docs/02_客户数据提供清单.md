# 02 · 客户数据提供清单

> 说 `导入对标账号` 之后，AI 会问你要素材。**你只需要准备下面这两样**，一条一条告诉 AI 就行，不用整理成表格。

---

## 你要提供的两样东西

### ① 账号主页链接

一个链接即可。可以是你**自己的账号**（想让 AI 诊断你的现状），也可以是**你想对标学习的账号**（想让 AI 拆解它的打法）。

### ② 这个账号的 5-10 条内容数据

每条内容提供 5 项数据（**标题 + 播放 + 点赞 + 评论 + 转发**），格式随意，AI 能看懂就行：

```
标题：怎么停止期待
播放：71w / 点赞 2.4w / 评论 899 / 转发 1.8w

标题：老板废话
播放：39w / 点赞 1.2w / 评论 567 / 转发 7.9k
```

**如果能再附上**：

- **top 5-10 条评论（带赞数）** — AI 能挖到"评论区模因层"（观众在玩什么梗）
- **你的印象**：这条算这个账号的「高表现 / 中表现 / 低表现」？为什么？— 这个判断比数据更重要，它告诉 AI 你想做成什么风格

---

## 数据从哪来（不用装任何工具）

| 平台 | 数据获取方式 |
|---|---|
| 小红书 | 打开笔记页面，播放/点赞/收藏/评论/转发都在页面下方 |
| 抖音 | 打开视频页面，播放/点赞/评论/转发在右侧或下方 |
| B 站 / YouTube | 视频页面直接可见 |
| 公众号 / Substack | 文章底部可见阅读/点赞 |

**脚本（文案）怎么拿**：

| 方式 | 说明 |
|---|---|
| 推荐 | 把你自己合法获取到的文案粘进对话即可（平台自带字幕 / 你整理过的文本） |
| 转录 | 你自行合法获取视频后，让 AI 用 whisper 转文字（需要装 whisper-cpp） |
| 偷懒 | 只给标题 + 数据 + 你的印象，AI 拆"标题级 pattern"，效果略浅但够起步 |

---

## 最少提供多少

- **最少 3 条**（少于 3 条 AI 拆不出 pattern，会拒绝）
- **推荐 5-10 条**（信号量和你的工作量平衡点）
- **单次上限 15 条**（太多 AI 处理不过来，可以分两次）

---

## 常见疑问

**Q：我一条内容的数据都记不全，怎么办？**
A：给标题 + 播放 + 点赞三样就够起步，评论/转发可以后补。AI 拆 pattern 主要靠脚本结构 + 你的印象。

**Q：我可以只提供链接，让 AI 自己爬数据吗？**
A：不能。本工具设计上不自动抓取平台数据（避免平台规则风险），数据一律由你手动提供。手动提供还有个好处：你会被迫"看一眼"每条内容，这个观察本身就是训练。

**Q：分析自己的账号和对标账号，流程一样吗？**
A：完全一样。把自己当 benchmark 导入 → AI 诊断你的现状；把对标账号导入 → AI 拆它的打法。两个都导也没问题（--append / --replace）。
